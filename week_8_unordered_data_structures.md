## Summary
This week introduces **unordered data structures** in Python, focusing on **sets** and **dictionaries**. You'll learn how sets store unique, immutable elements using hashing, how dictionaries map keys to values, and how to work with JSON files for data storage and retrieval. Exercises include creating sets from lists, manipulating dictionaries, iterating through data structures, and reading/writing JSON files.

### Key Terms & Definitions (Glossary)
- **set:** A collection of **distinct objects** (elements) with no duplicates. Sets are unordered and cannot be indexed. Elements must be immutable, though the set itself is mutable.
- **frozen set:** An **immutable set** in Python that cannot be modified after creation.
- **hashing:** A process that uses a **hashing algorithm** to generate a hash value for an element, determining how it should be stored and accessed in a set or dictionary.
- **hash value:** A unique numeric value generated by a hashing algorithm for an element, used to determine storage location.
- **dictionary:** A dynamic, mutable collection of **key-value pairs**. Keys are unique and used by the hashing algorithm; values can be duplicated. Since Python 3.7, dictionaries maintain insertion order.
- **key:** A unique identifier in a dictionary used to access its corresponding value. Keys must be immutable (strings, numbers, tuples).
- **value:** The data associated with a key in a dictionary. Values can be of any type and are not required to be unique.
- **key-value pair:** A combination of a key and its associated value in a dictionary.
- **JSON (JavaScript Object Notation):** A lightweight, text-based data format used for storing and transferring structured data. JSON files use `.json` extension.
- **cardinality:** The number of elements in a set, obtained using `len(s)`.
- **union:** A set operation that creates a new set containing all elements from both sets.
- **intersection:** A set operation that creates a new set containing only elements common to both sets.
- **difference:** A set operation that creates a new set containing elements in the first set but not in the second.
- **symmetric difference:** A set operation that creates a new set containing elements in either set but not both.
- **subset:** A set where every element is also in another set.
- **superset:** A set that contains all elements of another set.
- **iterable:** An object that can be traversed (iterated) using constructs like `for` loops. Dictionaries, sets, lists, and tuples are iterable.
- **shallow copy:** A copy of a data structure that creates a new object but references the same nested objects. Changes to nested objects affect both the original and the copy.

# 1) Introduction: Why Unordered Data Structures?

So far, you've worked with:
- **Lists** — ordered, indexed collections that allow duplicates
- **Tuples** — ordered, immutable collections
- **Strings** — sequences of characters

However, there are scenarios where you need:
- **Unique elements only** (no duplicates) — sets
- **Fast lookups by key** rather than index — dictionaries
- **Efficient membership testing** — sets
- **Key-value relationships** — dictionaries

**Sets** are perfect when you need to:
- Remove duplicates from a collection
- Test membership quickly
- Perform mathematical set operations (union, intersection, etc.)

**Dictionaries** are ideal when you need to:
- Store data with meaningful labels (keys)
- Look up values by name rather than position
- Represent real-world mappings (e.g., student ID → student name)

**JSON files** allow you to:
- Store structured data persistently
- Exchange data between programs
- Work with nested, hierarchical data

# 2) Sets: Overview and Properties

A **set** is a collection of distinct objects (elements) with the following characteristics:

### Key Properties:
1. **No duplicates** — Each element appears only once
2. **Unordered** — Elements have no defined order (cannot be indexed)
3. **Immutable elements** — Elements must be immutable (strings, numbers, tuples)
4. **Mutable set** — The set itself can be modified (add, remove elements)
5. **Uses hashing** — Internally uses hash values for efficient storage and lookup

### Mathematical Foundation:
Sets are based on **Set Theory** in mathematics. Python sets support operations like:
- Union (∪)
- Intersection (∩)
- Difference (−)
- Symmetric Difference (△)

### Example:
```python
# A set of web browsers
web_browsers = {"Chrome", "Firefox", "Edge"}

# Duplicates are automatically removed
observations = {"Car", "Sky Scraper", "Sky Scraper", "Bike", "House", "House"}
# Result: {'Car', 'Sky Scraper', 'Bike', 'House'}
```

There are several ways to create sets in Python:

### Method 1: Empty Set
```python
# Create an empty set
web_browsers = set()
# Note: {} creates an empty dictionary, not a set!
```

### Method 2: Set with Initial Elements
```python
# Create and initialize a set
web_browsers = {"Chrome", "Firefox", "Edge"}
```

### Method 3: From Other Data Structures
```python
# From a list
my_list = [1, 2, 2, 3, 3, 3]
my_set = set(my_list)  # {1, 2, 3}

# From a tuple
my_tuple = (1, 2, 2, 3)
my_set = set(my_tuple)  # {1, 2, 3}

# From a string
my_string = "hello"
my_set = set(my_string)  # {'h', 'e', 'l', 'o'}
```

### Method 4: Set of Tuples
```python
# Sets can contain tuples (immutable)
web_browser_usage = {("Chrome", 10), ("Firefox", 9), ("Edge", 3)}
```

# 4) Set Operations and Methods

### Basic Operations

| Operation | Description | Example |
|-----------|-------------|---------|
| `len(s)` | Number of elements (cardinality) | `len(web_browsers)` |
| `x in s` | Test membership | `"Chrome" in web_browsers` |
| `x not in s` | Test non-membership | `"Safari" not in web_browsers` |

### Modifying Sets

| Method | Description | Example |
|--------|-------------|---------|
| `s.add(el)` | Add element `el` to set `s` | `web_browsers.add("Safari")` |
| `s.discard(el)` | Remove `el` if present (no error if missing) | `web_browsers.discard("Edge")` |
| `s.remove(el)` | Remove `el` if present (raises `KeyError` if missing) | `web_browsers.remove("Edge")` |
| `s.clear()` | Remove all elements | `web_browsers.clear()` |
| `s.copy()` | Create a shallow copy | `new_set = web_browsers.copy()` |

### Set Theory Operations

| Method | Operator | Description | Example |
|--------|----------|-------------|---------|
| `s.union(t)` | `s \| t` | Elements in either set | `set1.union(set2)` |
| `s.intersection(t)` | `s & t` | Elements in both sets | `set1.intersection(set2)` |
| `s.difference(t)` | `s - t` | Elements in `s` but not in `t` | `set1.difference(set2)` |
| `s.symmetric_difference(t)` | `s ^ t` | Elements in either set but not both | `set1.symmetric_difference(set2)` |
| `s.issubset(t)` | `s <= t` | True if all elements of `s` are in `t` | `set1.issubset(set2)` |
| `s.issuperset(t)` | `s >= t` | True if all elements of `t` are in `s` | `set1.issuperset(set2)` |

### Examples:
```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Union
print(set1.union(set2))  # {1, 2, 3, 4, 5, 6}
print(set1 | set2)       # {1, 2, 3, 4, 5, 6}

# Intersection
print(set1.intersection(set2))  # {3, 4}
print(set1 & set2)              # {3, 4}

# Difference
print(set1.difference(set2))  # {1, 2}
print(set1 - set2)            # {1, 2}

# Symmetric Difference
print(set1.symmetric_difference(set2))  # {1, 2, 5, 6}
print(set1 ^ set2)                      # {1, 2, 5, 6}
```

# 5) Working with Sets: Practical Examples

### Example 1: Simple Set Creation
```python
def observed():
    """Create a set of observations with duplicates removed."""
    observations = {"Car", "Sky Scraper", "Sky Scraper", "Bike", "House", "House"}
    return observations

def run_task1():
    """Display the set of observations."""
    obs_set = observed()
    print(obs_set)

```

### Example 2: Creating Set from List with Counts
```python
def observed_items():
    """Read 7 observations from user and return as list."""
    observations = []
    for i in range(7):
        item = input("Please enter an observation: ")
        observations.append(item)
    return observations

def run_task2():
    """Count observations and display unique items with counts."""
    print("Counting observations...")
    obs_list = observed_items()
    
    # Create set of tuples (item, count)
    obs_set = set()
    for item in obs_list:
        count = obs_list.count(item)
        obs_set.add((item, count))
    
    # Display results
    for item, count in obs_set:
        print(f"{item} observed {count} times.")

run_task2()
```

### Example 3: Sorting Sets
```python
# Sets cannot be sorted directly, but sorted() returns a list
web_browsers = {"Chrome", "Firefox", "Edge", "Safari"}

# Sort alphabetically
sorted_browsers = sorted(web_browsers)
print(sorted_browsers)  # ['Chrome', 'Edge', 'Firefox', 'Safari']

# Sort in reverse
sorted_reverse = sorted(web_browsers, reverse=True)
print(sorted_reverse)  # ['Safari', 'Firefox', 'Edge', 'Chrome']
```

# 6) Dictionaries: Overview and Properties

A **dictionary** is a collection of **key-value pairs** with the following characteristics:

### Key Properties:
1. **Key-value pairs** — Each element consists of a key and its associated value
2. **Unique keys** — Keys must be unique within a dictionary
3. **Mutable keys** — Keys must be immutable (strings, numbers, tuples)
4. **Mutable values** — Values can be of any type and can be duplicated
5. **Ordered** — Since Python 3.7, dictionaries maintain insertion order
6. **Uses hashing** — Keys are hashed for efficient lookup

### Real-World Analogy:
Think of a dictionary like a phone book:
- **Key** = person's name (unique identifier)
- **Value** = phone number (data associated with the name)

### Example:
```python
# Dictionary of wedding items
wedding = {"Cake": 1, "Car": 1, "Ribbons": 100}

# Dictionary of student information
student = {
    "name": "John Doe",
    "id": "B001",
    "course": "Computing Systems",
    "year": 2
}
```

# 8) Dictionary Operations and Methods

### Basic Operations

| Operation | Description | Example |
|-----------|-------------|---------|
| `len(d)` | Number of key-value pairs | `len(wedding)` |
| `x in d` | Test if `x` is a key | `"Cake" in wedding` |
| `d["k"]` | Access value by key | `wedding["Cake"]` |
| `d["k"] = v` | Add or update key-value pair | `wedding["Cake"] = 2` |
| `del d["k"]` | Delete key-value pair | `del wedding["Cake"]` |

### Dictionary Methods

| Method | Description | Example |
|--------|-------------|---------|
| `d.keys()` | Returns view of all keys | `wedding.keys()` |
| `d.values()` | Returns view of all values | `wedding.values()` |
| `d.items()` | Returns view of all key-value pairs | `wedding.items()` |
| `d.get(key, default)` | Get value for key, return default if missing | `wedding.get("Cake", 0)` |
| `d.pop(key)` | Remove and return value for key | `wedding.pop("Cake")` |
| `d.popitem()` | Remove and return last inserted item | `wedding.popitem()` |
| `d.clear()` | Remove all key-value pairs | `wedding.clear()` |
| `d.copy()` | Create a shallow copy | `new_dict = wedding.copy()` |
| `d.update(other)` | Update dictionary with key-value pairs from `other` | `wedding.update({"Flowers": 50})` |

### Examples:
```python
wedding = {"Cake": 1, "Car": 1, "Ribbons": 100}

# Access values
print(wedding["Cake"])  # 1

# Add new key-value pair
wedding["Flowers"] = 50

# Update existing value
wedding["Cake"] = 2

# Check if key exists
if "Cake" in wedding:
    print("Cake is in the wedding dictionary")

# Get value with default
cakes = wedding.get("Cake", 0)  # Returns 2
balloons = wedding.get("Balloons", 0)  # Returns 0 (default)

# Remove item
cakes = wedding.pop("Cake")  # Removes "Cake" and returns 2
```

# 9) Iterating Through Dictionaries

Dictionaries are **iterable**, meaning you can loop through them. There are several ways to iterate:

### Method 1: Iterate Through Keys (Default)
```python
wedding = {"Cake": 1, "Car": 1, "Ribbons": 100}

# Iterate through keys (default behavior)
for key in wedding:
    print(key)

# Output:
# Cake
# Car
# Ribbons

# Explicitly using .keys()
for key in wedding.keys():
    print(key)
```

### Method 2: Iterate Through Values
```python
wedding = {"Cake": 1, "Car": 1, "Ribbons": 100}

# Iterate through values
for value in wedding.values():
    print(value)

# Output:
# 1
# 1
# 100
```

### Method 3: Iterate Through Key-Value Pairs
```python
wedding = {"Cake": 1, "Car": 1, "Ribbons": 100}

# Iterate through key-value pairs
for key, value in wedding.items():
    print(f"{key}: {value}")

# Output:
# Cake: 1
# Car: 1
# Ribbons: 100
```

### Complete Example:
```python
def display_keys(data):
    """Display all keys in the dictionary."""
    print("Keys:")
    for key in data:
        print(key)

def display_values(data):
    """Display all values in the dictionary."""
    print("Values:")
    for value in data.values():
        print(value)

def display_items(data):
    """Display all key-value pairs in the dictionary."""
    print("Pairs:")
    for key, value in data.items():
        print(f"{key}: {value}")

def pattern():
    """Create and return a dictionary of sequences."""
    sequences = {
        "Short Sequence": 3,
        "Medium Sequence": 2,
        "Long Sequence": 1
    }
    return sequences

def run():
    """Main function to demonstrate dictionary iteration."""
    data = pattern()
    print("Dictionary:")
    print(data)
    print()
    
    display_keys(data)
    print()
    display_values(data)
    print()
    display_items(data)

run()
```

# 11) JSON Files: Introduction

**JSON (JavaScript Object Notation)** is a lightweight, text-based data format used for:
- Storing structured data
- Exchanging data between programs
- Representing nested, hierarchical data

### JSON Structure:
- Uses **key-value pairs** (like dictionaries)
- Keys are always **strings**
- Values can be: strings, numbers, booleans, arrays (lists), objects (dictionaries), or `null`
- Uses **curly braces `{}`** for objects
- Uses **square brackets `[]`** for arrays
- Elements separated by **commas**

### Example JSON File:
```json
{
  "location": "Earth",
  "bots": [
    {
      "id": 1,
      "name": "Bender",
      "quote": "I am Bender, please insert girder",
      "stats": {
        "speed": 5,
        "strength": 8
      }
    },
    {
      "id": 2,
      "name": "Robot Santa",
      "quote": "Ho ho ho!!!",
      "stats": {
        "speed": 3,
        "strength": 10
      }
    }
  ],
  "population": 1000000
}
```

### Python-JSON Mapping:
- JSON `object` → Python `dict`
- JSON `array` → Python `list`
- JSON `string` → Python `str`
- JSON `number` → Python `int` or `float`
- JSON `boolean` → Python `bool`
- JSON `null` → Python `None`

# 12) Reading JSON Files

To read JSON files in Python, use the `json` module:

### Basic Syntax:
```python
import json

# Open and read JSON file
with open("filename.json", "r") as file:
    data = json.load(file)
```

### Step-by-Step Example:
```python
import json

# Step 1: Open the file
with open("futurama.json", "r") as file:
    # Step 2: Load JSON data
    data = json.load(file)
    
    # Step 3: Access data using keys
    location = data["location"]
    print(f"Place Name: {location}")
    
    # Step 4: Access nested data
    bots = data["bots"]
    for bot in bots:
        name = bot["name"]
        stats = bot["stats"]
        print(f"{name} has the following stats: {stats}")
```

### Complete Example:
```python
import json

def read(file_path):
    """Read and display content from a JSON file."""
    with open(file_path, "r") as file:
        data = json.load(file)
        
        # Display location
        location = data["location"]
        print(f"Place Name: {location}")
        
        # Display population
        population = data["population"]
        print(f"Population Size: {population}")
        
        # Display bot information
        bots = data["bots"]
        for bot in bots:
            name = bot["name"]
            stats = bot["stats"]
            strength = stats["strength"]
            speed = stats["speed"]
            print(f"{name} has a strength level of {strength} and a speed level of {speed}.")

def run():
    """Main function to read JSON file."""
    read("futurama.json")

if __name__ == "__main__":
    run()
```

# 13) Writing JSON Files

To write data to JSON files, use the `json.dump()` method:

### Basic Syntax:
```python
import json

data = {
    "name": "Bender",
    "type": "Bot"
}

# Write to JSON file
with open("exported.json", "w") as file:
    json.dump(data, file, indent=4)
```

### Parameters:
- `data` — The Python object (dict, list) to convert to JSON
- `file` — The file object to write to
- `indent` — Number of spaces for indentation (makes file readable)

### Complete Example:
```python
import json

def read_task2(file_path):
    """Read JSON content from a file."""
    print("Reading...")
    with open(file_path, "r") as file:
        data = json.load(file)
    print("Done!")
    return data

def save(file_path, data):
    """Save data to a JSON file."""
    print("Exporting...")
    with open(file_path, "w") as file:
        json.dump(data, file, indent=4)
    print("Done!")

def run_task2():
    """Read from one file and save to another."""
    json_data = read_task2("futurama.json")
    save("exported.json", json_data)

if __name__ == "__main__":
    run_task2()
```

## Exercise 3: Remove Observations and Sort
**Task:** Allow user to remove observations from a list, then display sorted unique observations with counts.

```python
def observed_items():
    """Read 5 observations from user and return as list."""
    observations = []
    for i in range(5):
        item = input("Please enter an observation: ")
        observations.append(item)
    return observations

def remove_observations(observations):
    """Allow user to remove observations from the list."""
    while True:
        choice = input("Do you wish to remove an observation (yes/no)? ")
        if choice.lower() != "yes":
            break
        
        item_to_remove = input("What observation do you wish to remove? ")
        if item_to_remove in observations:
            observations.remove(item_to_remove)
            print("Done!")
        else:
            print("Observation not found!")

def run_task3():
    """Main function to handle observations."""
    print("Counting observations...")
    obs_list = observed_items()
    remove_observations(obs_list)
    
    # Create set of tuples (item, count) and sort
    obs_set = set()
    for item in obs_list:
        count = obs_list.count(item)
        obs_set.add((item, count))
    
    # Sort and display
    sorted_obs = sorted(obs_set)
    print("Observations:")
    for item, count in sorted_obs:
        print(f"{item} observed {count} times")

run_task3()
```

# 15) Common Pitfalls & Tips

### Sets:
- **Empty set confusion:** `{}` creates an empty dictionary, not a set. Use `set()` for empty sets.
- **Mutable elements:** Sets cannot contain mutable elements (lists, dictionaries). Use tuples or frozen sets instead.
- **No indexing:** Sets are unordered and cannot be accessed by index. Use iteration or membership testing.
- **Modifying during iteration:** Be careful when modifying a set while iterating. Consider creating a copy first.
- **Hashable requirement:** Only hashable (immutable) objects can be set elements.

### Dictionaries:
- **Key errors:** Accessing a non-existent key with `d["key"]` raises `KeyError`. Use `d.get("key", default)` for safe access.
- **Mutable keys:** Dictionary keys must be immutable. Lists and dictionaries cannot be keys.
- **Order preservation:** Dictionaries maintain insertion order (Python 3.7+), but don't rely on order for logic unless necessary.
- **Shallow copy:** `dict.copy()` creates a shallow copy. Nested dictionaries are not deeply copied.
- **Key uniqueness:** Adding a value with an existing key overwrites the previous value.

### JSON:
- **File mode:** Always use `"r"` for reading and `"w"` for writing JSON files.
- **Indentation:** Use `indent=4` in `json.dump()` for readable output.
- **String keys:** JSON keys must be strings. Python will convert non-string keys to strings.
- **File closing:** Use `with` statement to ensure files are properly closed.
- **Error handling:** Consider using try-except blocks when reading JSON files that might not exist.

### General Tips:
- **Use sets for uniqueness:** When you need to remove duplicates, sets are more efficient than lists.
- **Use dictionaries for lookups:** Dictionaries provide O(1) average lookup time, much faster than searching through lists.
- **JSON for persistence:** Use JSON files to save program state or exchange data between programs.
- **Nested structures:** Both dictionaries and JSON support nested structures for complex data modeling.

# To Think About

- **When to use sets vs lists:** Sets are faster for membership testing and automatically remove duplicates, but lists maintain order and allow duplicates.
- **Dictionary key design:** Choose meaningful, immutable keys that uniquely identify values.
- **JSON structure:** Design your JSON structure to match how you'll access the data in your program.
- **Data persistence:** JSON files allow your program to remember data between runs. What happens if the JSON file is corrupted or missing?
- **Nested structures:** Deeply nested dictionaries and JSON can become complex. Consider if your data structure is too complicated.

**Extension topics:**
- **Set comprehensions:** Similar to list comprehensions, you can create sets using set comprehensions: `{x**2 for x in range(10)}`
- **Dictionary comprehensions:** Create dictionaries using comprehensions: `{x: x**2 for x in range(10)}`
- **JSON validation:** Learn about JSON schema validation to ensure data integrity
- **Alternative formats:** Explore other data formats like CSV, XML, or YAML for different use cases
